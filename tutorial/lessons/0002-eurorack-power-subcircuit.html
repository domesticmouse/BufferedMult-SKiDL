How @subcircuit Maps a Python Function to KiCad Hierarchy

In buffered_multiple.py (lines 83–151), the power entry block is written as a plain Python function decorated with @subcircuit: def eurorack_power(vcc, vee, gnd):.

Decorating a function with Subcircuit Decorator (@subcircuit) does two important things in SKiDL:

  1. Interface Nets vs. Local Nets: The top-level protected rails (vcc, vee, gnd) are passed in as function arguments so downstream op-amp channels can attach to them, while the raw header nets (vcc_raw = Net("+12V_RAW") and vee_raw = Net("-12V_RAW")) remain private to eurorack_power.
  2. Deterministic Hierarchical Path Tags: When the top-level circuit calls eurorack_power(vcc, vee, gnd, tag="pwr") and each internal part defines a tag (such as tag="j_pwr", tag="d_prot", tag="c_bulk"), SKiDL hashes the hierarchical path (/pwr/c_bulk) into a deterministic KiCad tstamp UUID. Re-running your Python script never scrambles component associations in KiCad's PCB editor!

1. Multi-Pin Tuple Indexing on the 10-Pin Eurorack IDC Header

As we verified in Lesson 0001, the 10-pin (`2×5`) Eurorack power connector uses KiCad 10's Connector_Generic:Conn_02x05_Odd_Even symbol and Connector_IDC:IDC-Header_2x05_P2.54mm_Vertical footprint. Instead of writing ten separate += statements, SKiDL lets you index multiple pins in a single tuple subscript:

  • vee_raw += j_pwr[1, 2] wires pins 1 and 2 (the -12V red-stripe end) to -12V_RAW.
  • gnd += j_pwr[3, 4, 5, 6, 7, 8] wires all six center ground pins to GND in one statement.
  • vcc_raw += j_pwr[9, 10] wires pins 9 and 10 to +12V_RAW.

2. Bipolar Schottky Diode & Bulk Capacitor Polarity

Even when you know bipolar power supplies well, expressing -12V diode and electrolytic capacitor orientation in code requires care with pin names (`"A"`, `"K"`) and numbers (`1`, `2`):

Pin-by-pin polarity in eurorack_power(vcc, vee, gnd)
Component Rail SKiDL Wiring Electrical Reason
d_pos (D1, 1N5819WS) +12V vcc_raw += d_pos["A"]
vcc += d_pos["K"]		 Conventional current flows out of the header (+12V_RAW) into the Anode (A) and exits the Cathode (K) into the module's +12V rail.
d_neg (D2, 1N5819WS) -12V vee_raw += d_neg["K"]
vee += d_neg["A"]		 On the negative rail, conventional current returns from the module's -12V rail (vee) into the Anode (A) and exits the Cathode (K) back into the header (-12V_RAW).
c_bulk_pos (C1, 10uF) +12V to GND vcc += c_bulk_pos[1]
gnd += c_bulk_pos[2]		 +12V is positive relative to 0V, so pin 1 (+ anode) connects to vcc and pin 2 (- cathode) connects to gnd.
c_bulk_neg (C2, 10uF) GND to -12V gnd += c_bulk_neg[1]
vee += c_bulk_neg[2]		 0V (GND) sits at a higher potential than -12V! Therefore pin 1 (+ anode) must connect to gnd and pin 2 (- cathode) to vee.
