Growing the Script: Adding buffered_channel_1to3()

Take our Stage 2 power supply script and grow it by adding @subcircuit def buffered_channel_1to3(...) around a single quad TL074H op-amp: wire input ESD/TVS clamping, Stage A input buffering, three loop-generated output followers with 470R series isolation, and builtins.NC on unused jack switches.

Script Growth: 155 → 255 Lines (18 Parts) ✓ ERC: 0 Errors, 0 Warnings ✓ Ruff: Clean

Anatomy of buffered_channel_1to3

In Lesson 0002, our script reached 155 lines with a verified eurorack_power(vcc, vee, gnd) subcircuit. Now we add a second reusable @subcircuit directly below eurorack_power: def buffered_channel_1to3(vcc, vee, gnd, norm_in, buffered_tap_out, ch_num=1):.

Each 1-to-3 channel maps all four internal operational amplifiers of one TL074H (SOIC-14) package to a two-tier buffer hierarchy:

  • Stage A (Input Follower, Pins 1, 2, 3): Presents a high-impedance load (100K pull-down) to the patched CV/audio source and produces a low-impedance buffered signal on buffered_tap_out.
  • Stages B, C, D (Output Followers, Pins 5–14): Three independent unity-gain followers driven by buffered_tap_out, each driving its own output jack through a 470R series protection resistor so a short circuit or cable capacitance on one output never disturbs the other two outputs—or any downstream normalled channel.

Why Output Jacks Use j_out["TN"] += builtins.NC (Pin on the Left)

All 12 jacks on the board use the same physical part (WQP-PJ398SM / AudioJack2_SwitchT) to simplify purchasing and panel assembly. On the output jacks, the Switched Tip Normal Contact (TN) is unused. In SKiDL, the No-Connect Net (builtins.NC) is injected into Python's builtins module at import time and is not exported in skidl.__all__ (so from skidl import NC raises ImportError). Furthermore, inside a function or @subcircuit, writing builtins.NC += j_out["TN"] makes Python treat builtins.NC as a reassigned local variable; always place the pin on the left: j_out["TN"] += builtins.NC.
